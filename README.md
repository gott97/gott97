## Featured GIS Projects

### 🌲 Seattle Public Tree Inspection Prioritization

**Python • ArcPy • ArcGIS Pro • ArcGIS Online • Dashboards • StoryMaps**

A reproducible GIS workflow for comparing 20,992 public tree assets and developing a modeled Year 1 inspection program. The project combines tree characteristics, inspection timing, public exposure, and neighborhood equity context in a transparent 0–100 Inspection Priority Index.

The final deliverables include a citywide interactive map, an operational dashboard, a 1,050-tree Year 1 program, documented methodology, and six Jupyter notebooks.

[View the GitHub repository](https://github.com/gott97/seattle-tree-inspection-priority)  
[Explore the StoryMap](https://storymaps.arcgis.com/stories/5922814130cb4af689ecb57017f72b75)  
[Open the citywide priority map](https://arcg.is/0PbDeq0)

### 🌡️ Phoenix Urban Heat and Tree Canopy Equity

**Python • ArcPy • Remote Sensing • Census Data • ArcGIS Online**

A reproducible spatial analysis integrating Landsat surface-temperature imagery, NLCD tree-canopy data, and American Community Survey indicators to identify areas where elevated heat exposure and limited canopy overlap with social vulnerability.

The project includes five documented notebooks, a hosted analysis layer, an interactive web map, and a StoryMap explaining the workflow, findings, and limitations.

[View the GitHub repository](https://github.com/gott97/urban-heat-equity-phoenix)  
[Explore the StoryMap](https://storymaps.arcgis.com/stories/e975b895c9354858ac33ba7044ac577a)
